Role-Based Access

Admin and User dashboards are intentionally different

Admin users see management-level summaries and user administration. Standard users see only the billing follow-up areas they need for daily work. The route guard redirects any user who tries to open a dashboard that does not match their role.

Admin: KPIs, chart, users User: daily invoices, focused summary Guard: prevents admin-only visibility

Dashboard Logic

Dashboard numbers are calculated from invoice records

Today Revenue SUM paid amounts for invoices created today
Receivables SUM total invoice value minus paid amount
Invoice Count COUNT invoice records in the local dataset
